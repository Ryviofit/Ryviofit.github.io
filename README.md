# PULSE//RUN public site

This repository hosts the public legal, privacy and support pages for
PULSE//RUN.

GitHub Pages: https://ryviofit.github.io/PulseRun-public/

The game source code and internal release documentation are maintained in a
separate private repository. Public policy pages will be published here only
after their legal identity, contact information, purchase-processing details
and advertising declarations have been finalized and reviewed.

The project Pages path can host the legal and support pages. AdMob's
`app-ads.txt` must be served from the developer website's domain root, so that
record requires either a verified custom domain or a separate root user Pages
repository named `Ryviofit.github.io`.
